SweepDocument hygiene scanner

The last check before a document leaves the building.

What you see on screen isn't everything in the file. Sweep finds the hidden sheets, tracked changes, embedded objects, password protection and personal data sitting where nobody thought to look, and cleans them out before release.

Works on Excel (.xlsx), Word (.docx) and PDF files through one pipeline.

How it works

Scan, review, clean. With proof it was done.

STAGE 01

Scan and detect

Sweep reads how the file is built, not how it looks.

  • Parses the file's actual container format, not just what renders on screen
  • Finds hidden sheets, tracked changes and embedded objects
  • Extracts text from every layer, including hidden content
  • Flags encrypted and password-protected files
STAGE 02

Flag and review

You decide what gets fixed.

  • Findings tagged by severity, with their exact location
  • Personal data detected in visible and hidden content alike
  • An interactive review panel to choose what to fix
  • Catches fake redactions in PDFs: selectable text sitting under a black box
STAGE 03

Clean and audit

A clean copy out, a record kept.

  • One-click remediation
  • Writes a sanitized copy and never modifies the original
  • An exportable, timestamped audit report of every check
  • Nothing retained by default
Capabilities

Two engines, one required step.

Rule-based engine

The default. It runs locally, so documents never leave to be checked.

AI-assisted engine

Opt in for broader coverage when rules alone aren't enough.

Proof of the check

Every scan produces a timestamped report, so you can show a document was checked before it went out.

Pairs with Docket

Run Sweep self-hosted next to Docket, or use the hosted scan service.
