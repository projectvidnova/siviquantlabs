iReviewCode review

AI code review that reasons out loud.

iReview reviews every pull request with the context of your whole codebase. It flags bugs, security issues and style problems before a human reviewer picks it up, and streams its reasoning so you can see how it got there.

Works with GitHub, GitHub Enterprise Server and Azure DevOps. Supports TypeScript, Python, Java, Go, C# and more, with guidelines for each language.

How it works

From pull request to posted comment, in three stages.

STAGE 01

Ingest and build context

Paste a pull request link, or let a webhook start the review.

  • Non-source files filtered out by more than 35 patterns: tests, lock files, generated code, binaries
  • Changed files split at syntax-tree boundaries and indexed per project for semantic search
  • Language and framework detected automatically
STAGE 02

Analyze and validate

A draft pass, then a second pass that checks the draft.

  • Relevant existing code and the signatures of called functions added as context, which keeps suggested fixes grounded
  • Draft findings ranked critical, high, medium or low
  • The self-check confirms line numbers, makes sure fixes would actually run, and drops low-confidence findings
  • Existing threads and earlier reviews checked, so the same point isn't raised twice
STAGE 03

Post and track

Findings land where your team already works.

  • Comments posted straight into the GitHub or Azure DevOps thread
  • Reasoning streamed live and stored for replay
  • Token use, model and cost recorded for every review
